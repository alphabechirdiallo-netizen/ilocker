# ilocker Studio

Centre de commandes visuel pour [ilocker](https://github.com/alphabechirdiallo-netizen/ilocker) — parcourez, cherchez et lancez les 202 commandes sans jamais mémoriser la syntaxe.

## Fonctionnalités
- Centre de commandes plein écran, catégorisé, avec recherche
- Historique des snapshots (timeline)
- État de déploiement (GitHub / Vercel / Supabase)
- Historique d'activité (commandes lancées depuis l'extension)
- Assistant docké dans la barre latérale, contextuel

## Prérequis
Le binaire `iloc` doit être installé et accessible dans le PATH (ou configuré via `ilockerStudio.binaryPath`).
